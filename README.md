# Banking Analytics Project

## Project Overview
This project analyzes a banking loan portfolio to understand loan distribution, client activity, repayment performance, and loan status. It presents key banking metrics and business insights through data analysis and dashboards.

## Project Objectives
- Analyze the overall loan portfolio and funded amount.
- Understand the number of clients represented in the data.
- Compare loan amounts across branches and loan grades.
- Review loan statuses such as Active, Closed, Defaulted, and Delinquent.
- Analyze principal repayment performance.
- Present key metrics through dashboards.

## Tools & Technologies
- Microsoft Excel – data inspection and cleaning
- MySQL – data storage and SQL analysis
- Power BI – KPI reporting and interactive dashboard
- Tableau – data visualization and dashboard exploration
- Kaggle Notebook – project notebook and analysis

## Dataset
The banking dataset includes fields such as Client ID, Account ID, Branch Name, Disbursement Date, Loan Status, Loan Grade, Loan Amount, Funded Amount, Total Received Principal, and Total Fees.

## Data Preparation
The preparation process included:
- Reviewing column names and data types.
- Removing unnecessary blank columns.
- Checking for duplicate records and missing values.
- Trimming extra spaces from text fields.
- Standardizing fields used for analysis.
- Preparing the cleaned data for reporting.

## Key Performance Indicators
- Total Funded Amount
- Total Clients
- Total Principal Received
- Average Funded Amount

Refer to the final dashboard or notebook for the calculated KPI values.
